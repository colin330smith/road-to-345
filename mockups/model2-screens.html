Exercise scientist

Dose you can see

  • Stimulus per muscle, not per exercise. The Physique map counts weekly fractional sets (a compound set counts half, as in Pelland 2025) and shades each muscle by where it sits on the dose-response curve.
  • Honest uncertainty. A goal only reads ahead or behind once the trend beats tape noise. Body fat from the tape is a trend, and one DXA scan calibrates it.
  • Effort is measured, not guessed. One rating on the top single feeds the RPE chart and moves the back-offs the same morning.
Powerbuilder

The bar comes first

  • Plates per side on every barbell set, so the bar gets loaded without math.
  • USPA commands on every heavy single (START, PRESS, RACK), so meet day feels rehearsed.
  • The frame work is visible: the session ends by counting what it added to upper chest, side and rear delts, triceps and traps.
Personal trainer

One cue, one reason

  • One coaching cue per set, the one that fixes the most common mistake on that lift.
  • A one-line "why" under each exercise ties it to your goal: 16" arms, 3D shoulders, the upper chest, the yoke.
  • A last set worth chasing: the anchor set is flagged "to RPE 9–10" and everything else stops short, so effort goes where it pays.
App developer

Zero thinking at 7 AM

  • One screen, one action: Log → (rate) → rest → next, with the thumb never leaving the bottom third.
  • 84–92 pt numerals readable at arm's length, a ring for progress and an honest minutes-left estimate.
  • Motion that means something: the button flashes on log, the ring fills, the rest dial drains. Nothing decorative, and reduce-motion is respected.
